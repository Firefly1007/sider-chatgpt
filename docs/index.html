01下载后即可加载

在 Release 页面下载 sider-chatgpt-1.0.0.zip 并解压。在 Edge 的扩展管理页开启开发人员模式，选择“加载解压缩的扩展”，加载含有 manifest.json 的 Sider-ChatGPT 文件夹。

在普通标签页登录 ChatGPT，再刷新阅读网页。安装成品包无需编译，也无需配置 API Key。

02从选区开始，也可以继续追问

划词悬浮栏提供问 AI、解释、翻译、总结、搜索和脑图。回答在原位浮窗中显示，支持 Markdown、公式和图表。你也可以打开侧栏，附加选中文字或当前网页。

使用之前，了解数据如何处理

执行任务时，问题、选中文字及相关网页背景会发送给 ChatGPT。部分功能使用提取后的整篇网页正文；“附加当前网页”会直接发送材料。

扩展没有开发者自建的数据接收服务器。ChatGPT 的数据处理适用其政策，关闭浮窗不等于删除服务端内容。

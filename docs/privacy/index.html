先了解这三点

  • 执行任务时，问题、选中文字和相关网页材料会发送给 ChatGPT；部分功能会附带提取后的整篇网页正文。
  • 扩展没有开发者自建的数据接收服务器；设置保存在本地，任务正文不写入扩展的持久化存储。
  • ChatGPT 自身的数据处理适用其政策。关闭浮窗不等于删除服务端数据。

01适用范围

Sider ChatGPT 是由 Firefly1007 维护的 Microsoft Edge 扩展，用于通过已登录的 ChatGPT 网页辅助阅读、解释、翻译、总结、搜索、脑图整理与问答。本政策覆盖本扩展及其隐私政策网站。

这是独立项目，不代表 OpenAI、Microsoft 或其他同名产品。你在 ChatGPT 原生网页中使用账号、上传文件或使用其他原生功能时，同时受该服务的条款、隐私政策与账号设置约束。

02我们处理哪些信息

信息类型处理范围与用途
问题与对话你输入的问题、追问、用于附加的草稿及 ChatGPT 返回的回答，用于执行任务、展示结果和继续对话。
网站内容所选文本、选区邻近段落或提取后的网页正文，用于为任务提供材料和背景。内容提取会排除表单、密码输入框、可编辑区和扩展自身界面。
当前网页信息任务所涉及网页的标题及 URL，可随网页背景提交给 ChatGPT。扩展读取当前标签页及导航状态以核对来源，不建立完整浏览历史档案。
设置与任务标识扩展开关、目标语言、思考程度、排除站点、界面兼容设置，以及关联标签页、文档和任务的技术标识，用于保存偏好和管理任务。

扩展不专门收集身份、健康、财务或定位资料，不提取账号密码、Cookie、登录令牌或 API Key，也不记录鼠标轨迹、按键或点击行为用于分析。你主动提交的正文或对话仍可能包含个人信息；扩展不提供完整的敏感信息识别或自动脱敏保证。

03内容何时会离开浏览器

  • 仅划词：显示悬浮栏，不发送问题或网页材料。
  • 点击快捷功能：解释、翻译、总结、搜索和脑图等功能会提交所选文本及对应背景。“解释”和“问 AI”使用提取后的网页正文作为背景；其他划词功能使用选区附近背景。“问 AI”在你输入问题并提交后发送。
  • 附加选区：划词栏的“附加”只把文本写入同窗口侧栏草稿，等待你发送。
  • 附加当前网页：点击侧栏输入框中的回形针会直接提交当前网页标题、URL 和提取后的正文；已有文本草稿会暂存并尝试恢复。
  • 预加载：启用扩展时会预加载 ChatGPT 网页及备用临时会话。预加载不发送问题或网页正文，但会产生到 ChatGPT 的正常网络连接。

提交通过 ChatGPT 网页及其原生对话控件完成。扩展没有将这些材料另行上传给开发者的接口，不使用开发者自建服务转发对话，不通过广告或数据交易使用任务内容。

04保存多久，如何删除

扩展本地设置：用户偏好保存在浏览器扩展的本地存储中。用于会话关联的技术标识保存在会话存储中；任务清理、浏览器会话结束等情况会更新或移除这些标识。扩展不使用云同步存储保存任务内容。

运行中的内容：问题、回答和暂存草稿在任务运行期间保留在页面或内存中，不写入扩展的持久化存储。关闭浮窗会释放其后台任务；你主动复制或导出的文本、图片和文件由你自行管理。

ChatGPT 服务端：浮窗使用 ChatGPT 临时聊天，侧栏使用普通 ChatGPT 网页。具体保存时间、历史记录、训练使用和删除方式由 OpenAI 的政策及你的账号设置决定，本扩展不能代替其完成服务端删除。

关闭浮窗、卸载扩展或清除扩展存储，都不表示已经删除提交给 ChatGPT 的内容。请在 ChatGPT 中管理相关对话及数据控制选项。

05第三方服务与网站托管

ChatGPT / OpenAI

ChatGPT 接收你提交的问题和材料。加载其网页时，浏览器可能发送该站点的登录 Cookie、IP 地址、设备及连接信息，网页也会执行自身的站点脚本；扩展本身不读取或提取这些认证凭据。此类处理由 OpenAI 负责，可能涉及你所在国家或地区以外的服务器。

请参阅 OpenAI 隐私政策及临时聊天说明，并检查自己的账号数据设置。

GitHub Pages / GitHub Issues

本隐私政策网站由 GitHub Pages 托管。页面不设置统计 Cookie，不加载分析脚本、广告或远程字体；GitHub 为提供托管与安全服务可能处理访问日志及 IP 地址，适用 GitHub 隐私声明。

如果你主动在仓库 Issues 联系维护者，你的 GitHub 用户名及提交内容会出现在公开的 Issue 中，并由 GitHub 保存。请勿提交密码、令牌、完整私人对话或其他敏感材料。

06你的选择与控制

  • 在扩展设置中关闭功能或添加排除站点；也可以通过浏览器的扩展管理限制网站访问权限。限制权限后，部分功能可能不可用。
  • 只在愿意提交相关内容的页面上启动任务；对敏感网页可先关闭扩展。请特别注意整篇正文背景和“附加当前网页”的直接发送行为。
  • 在浮窗中停止生成或关闭任务，在 ChatGPT 中管理历史对话、临时聊天和数据控制选项。
  • 卸载扩展以移除其浏览器本地设置；自行删除已经导出或复制的内容。
  • 通过下方联系渠道提出与本扩展有关的隐私问题。涉及 ChatGPT 账号或服务端数据的请求，需要通过 OpenAI 提供的渠道处理。

07权限与安全边界

扩展在普通 HTTP/HTTPS 网页中使用内容脚本处理划词和用户启动的材料提取，并使用侧栏、隐藏文档、标签页、导航和存储权限管理界面及任务。网站访问权限覆盖多个网站，以支持不同网页上的阅读辅助功能。

为在扩展自己的框架中显示 ChatGPT，扩展对由本扩展发起、目标为 ChatGPT 的子框架响应移除 Content-Security-Policy 与 X-Frame-Options 响应头。该规则不作用于普通网页发起的嵌入请求，关闭扩展功能后移除。

扩展自身脚本、Markdown、公式及脑图依赖随安装包提供，不通过远程脚本更新扩展逻辑。返回内容作为文本、Markdown 或经过清洗的图表呈现。任何软件和网络服务都无法保证绝对安全，请避免提交无权分享的内容。
